# Terminal AI Knowledge Vault

This folder serves as the local knowledge base and markdown vault for the terminal AI fleet:
- **Claude Code** (`claude`)
- **Google Gemini CLI** (`gemini`)
- **OpenCode** (`opencode`)
- **Codex / Universal Agents** (`AGENTS.md`)

## Structure
- `RESEARCH_LOGS.md`: Live automated findings, video summaries, and deep research drafts.
- `PROJECT_PLANS.md`: Active and upcoming technical architecture blueprints.
- `SCRIPTS_AND_IDEAS.md`: Video ideas, automation pipelines, and terminal workflows.

Agents have direct read and write permission to this directory.
